## 如何查看流程图

### 方法1：使用支持Mermaid的编辑器
- **Typora**: 直接打开.md文件即可渲染流程图
- **VS Code**: 安装"Markdown Preview Mermaid Support"插件
- **Obsidian**: 原生支持Mermaid语法

### 方法2：在线查看
访问 https://mermaid.live/
1. 复制流程图的mermaid代码块内容
2. 粘贴到在线编辑器
3. 即可查看和导出为PNG/SVG

### 方法3：命令行转换为图片
使用mermaid-cli工具：

```bash
# 安装mermaid-cli
npm install -g @mermaid-js/mermaid-cli

# 提取所有流程图并转换
mmdc -i 功能流程图.md -o 流程图输出目录/
```

## 如何转换为Word文档

### 使用Pandoc转换

```bash
# 安装pandoc
# Windows: choco install pandoc
# Linux: apt-get install pandoc
# macOS: brew install pandoc

# 转换为Word文档
pandoc 功能说明书.md -o 功能说明书.docx
pandoc 功能流程图.md -o 功能流程图.docx
```

### 手动转换
1. 使用Typora或VS Code打开Markdown文件
2. 导出为Word格式
3. 在Word中调整格式

## 流程图图例

- **浅绿色节点**: 流程开始
- **深绿色节点**: 成功结束
- **浅红色节点**: 异常结束

- **圆角矩形**: 开始/结束
