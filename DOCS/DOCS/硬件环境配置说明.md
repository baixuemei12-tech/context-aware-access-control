### 1.2 配置说明

**处理器性能**：
- 采用Intel第12代酷睿i7-12700F处理器
- 12核心（4性能核+8效能核），20线程

**内存配置**：
- 总容量：16 GB（实际可用约15.79 GB）

- **系统盘**：512 GB NVMe SSD，用于安装操作系统、开发工具、IDE
- **数据盘**：1 TB HDD，用于存储项目源代码、IPFS数据、日志文件、测试数据
- **总存储空间**：约1.5 TB

**图形处理**：
- NVIDIA GeForce GTX 1660 SUPER独立显卡
- 6 GB GDDR6显存
- 支持CUDA并行计算
- 适用于前端调试、数据可视化开发

**网络环境**：
- Intel Wi-Fi 6 AX201无线网卡
- 支持802.11ax协议（Wi-Fi 6）
- 最高理论速度2.4 Gbps
- 支持蓝牙5.2

## 三、分布式部署硬件配置

### 3.1 典型部署架构

本系统采用三层架构，典型部署需要以下硬件节点：

#### 节点1：Fabric区块链网络（PDP层）

| 配置项 | 规格要求 |
|-------|---------|
| **节点数量** | 至少2个组织，每个组织2个Peer节点 |
| **处理器** | Intel Xeon E5 / AMD EPYC 7002系列（8核） |
| **内存** | 16 GB |
| **硬盘** | 256 GB SSD（账本存储） |
| **网络** | 1000 Mbps以太网 |

#### 节点2：Oracle评估服务

| 配置项 | 规格要求 |
|-------|---------|
| **节点数量** | 1-2个（高可用部署） |
| **处理器** | Intel Xeon / AMD EPYC（4核） |
| **内存** | 8 GB |
| **硬盘** | 128 GB SSD |
| **网络** | 1000 Mbps以太网 |

#### 节点3：Gateway网关服务（PEP层）

| 配置项 | 规格要求 |
|-------|---------|
| **节点数量** | 2-4个（负载均衡） |
| **处理器** | Intel Xeon / AMD EPYC（8核） |
| **内存** | 16 GB |
| **硬盘** | 256 GB SSD |
| **网络** | 1000 Mbps以太网 |

#### 节点4：IPFS存储节点

| 配置项 | 规格要求 |
|-------|---------|
| **节点数量** | 3个及以上（分布式存储） |
| **处理器** | Intel Core i5 / AMD Ryzen 5（4核） |
| **内存** | 8 GB |
| **硬盘** | 2 TB HDD + 128 GB SSD（缓存） |
| **网络** | 1000 Mbps以太网 |

### 3.2 网络拓扑

```
                    Internet

        ┌──────────────┼──────────────┐
```

## 六、硬件扩展性说明

### 6.1 纵向扩展（Scale-up）

系统支持通过升级单节点硬件提升性能：

| 扩展项 | 扩展方案 | 性能提升 |
|-------|---------|---------|
| **CPU升级** | 升级至16核32线程 | 并发处理能力提升60% |
| **内存扩容** | 扩展至32 GB | 支持2000+并发会话 |
| **SSD升级** | 更换为NVMe 4.0 SSD | IPFS读写速度提升2倍 |
| **网卡升级** | 万兆以太网卡 | 传输吞吐量提升10倍 |

### 6.2 横向扩展（Scale-out）

系统支持通过增加节点数量实现水平扩展：

| 扩展层级 | 扩展方式 | 容量提升 |
|---------|---------|---------|
| **Gateway层** | 增加网关节点 | 线性扩展，每增加1节点提升25%吞吐 |
| **IPFS层** | 增加存储节点 | 存储容量线性增加 |
| **Fabric层** | 增加Peer节点 | 提升账本查询并发能力 |
