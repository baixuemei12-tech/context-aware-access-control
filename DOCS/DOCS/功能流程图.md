    AdjustMargin --> CheckMargin{margin < 0?}
    CheckMargin -->|是| RevokeDecision[决定撤销会话]
    CheckMargin -->|否| CheckTier{风险层级变化?}
    RevokeDecision --> MarkRevoked[标记为已撤销]
    MarkRevoked --> RecordCSRP[记录网络撤销事件]
    RecordCSRP --> NotifyRevoke[触发SESSION_REVOKED]
    NotifyRevoke --> NextSession
    CheckTier -->|是| UpdateTier[更新会话层级]
    CheckTier -->|否| CheckDeviation{DT偏差>5%?}
    UpdateTier --> UpdateInterval
    CheckDeviation -->|是| ResetAccel[重置加速n=0]
    CheckDeviation -->|否| IncrAccel[加速计数n++]
    ResetAccel --> UpdateInterval[更新轮询间隔]
    IncrAccel --> UpdateInterval
    UpdateInterval --> NotifyScore[触发SCORE_UPDATED]
    NotifyScore --> NextSession
    NextSession --> MoreSessions{还有会话?}
    MoreSessions -->|是| CheckTime
    MoreSessions -->|否| Sleep
    Sleep --> End([结束])
    
    style Start fill:#e8f5e9
    style End fill:#bbdefb
    style RevokeDecision fill:#ffcdd2
