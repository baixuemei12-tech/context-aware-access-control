## 如何使用这些文档

### 软著申请材料准备

1. **流程图转图片**
   ```bash
   # 使用mermaid-cli
   npm install -g @mermaid-js/mermaid-cli
   mmdc -i 功能流程图.md -o 流程图/
   ```

2. **Markdown转Word**
   ```bash
   # 使用pandoc
   pandoc 功能说明书.md -o 功能说明书.docx
   ```

3. **在Word中整合**
   - 将流程图插入到对应功能说明章节
